اتحاد ملاك بيت العيلة — نسخة أولية
- افتح index.html في Chrome على الكمبيوتر أو الهاتف.
- البيانات محفوظة محليًا في localStorage لهذا المتصفح والجهاز.
- يمكن تعديل أسماء السكان وتسجيل المدفوعات والمصاريف وتنزيل/استعادة JSON.
- تنبيه: Firebase غير مربوط. قبل الاستخدام الحقيقي يجب إعداد Firebase Auth + Firestore/Cloud backup وقواعد أمان، ثم اختبار المزامنة والنسخ الاحتياطي.
- هذه نسخة Web prototype وليست APK Android.
