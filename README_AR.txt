اتحاد ملاك بيت العيلة — مشروع تجهيز تطبيق Android

مهم:
- هذه حزمة مشروع Android وليست ملف APK جاهزًا بعد.
- التطبيق يفتح نسخة HTML داخل WebView ويحفظ بياناته محليًا على الهاتف عبر Local Storage.
- Firebase/المزامنة السحابية غير مفعّلة في هذه النسخة.
- احتفظ بنسخة JSON من داخل التطبيق قبل نقل البيانات أو تحديث التطبيق.

بناء APK دون Android Studio على الكمبيوتر:
1) فك ضغط هذا الملف.
2) أنشئ مستودعًا جديدًا على GitHub من المتصفح.
3) ارفع جميع الملفات والمجلدات كما هي إلى المستودع (بما فيها مجلد .github).
4) افتح تبويب Actions في المستودع، واختر Build Android APK ثم Run workflow إذا لم يبدأ البناء تلقائيًا.
5) بعد انتهاء البناء بنجاح، افتح نتيجة التشغيل وانزل إلى Artifacts.
6) نزّل beit-el3ela-debug-apk.zip وافتحه؛ ستجد app-debug.apk.
7) انقل APK إلى هاتف الإدارة وثبّته. قد يطلب Android السماح بالتثبيت من هذا المصدر.

ملاحظة الجهاز:
يمكن تنفيذ الرفع من متصفح الكمبيوتر؛ لا حاجة لتثبيت Android Studio محليًا.
